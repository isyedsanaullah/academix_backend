#### 11C: Teaching Pacing & LMS Knowledge (N23, N30, N31)

##### 1. N23 Lesson Plans & Syllabus Coverage Tracker (Premium Tier)
* **Institutional Job:** Pacing guide breaking down intermediate board subject curricula (e.g. FSc Part-1 Physics) into chapters and lecture units, tracking actual teacher completion dates against the academic calendar, and surfacing syllabus lag warnings to principals.
* **Data Models:**
  ```prisma
  model SyllabusBreakdown {
    id           String   @id @default(uuid())
    college_id   String
    campus_id    String?
    session_id   String
    class        String   // "FSc Part 1"
    subject_id   String
    boardName    String   // "BISE Lahore", "Federal Board"
    totalUnits   Int
    totalHours   Int
    isActive     Boolean  @default(true)
    createdAt    DateTime @default(now())

    units        SyllabusUnit[]
    @@unique([college_id, session_id, class, subject_id])
  }

  model SyllabusUnit {
    id          String   @id @default(uuid())
    breakdownId String
    unitNumber  Int
    title       String   // "Chapter 2: Vectors and Equilibrium"
    subTopics   String[] // ["Cartesian coordinate system", "Addition of vectors", "Torque"]
    targetWeek  Int      // Academic week number (1 to 32)
    expectedHours Int

    breakdown   SyllabusBreakdown @relation(fields: [breakdownId], references: [id], onDelete: Cascade)
    progress    TeacherSyllabusProgress[]
    @@unique([breakdownId, unitNumber])
  }

  model TeacherSyllabusProgress {
    id           String    @id @default(uuid())
    college_id   String
    campus_id    String?
    unitId       String
    section_id   String
    teacher_id   String
    status       String    @default("IN_PROGRESS") // NOT_STARTED | IN_PROGRESS | COMPLETED
    completedAt  DateTime?
    actualHours  Int       @default(0)
    notes        String?
    updatedAt    DateTime  @updatedAt

    unit         SyllabusUnit @relation(fields: [unitId], references: [id], onDelete: Cascade)
    @@unique([college_id, unitId, section_id])
    @@index([college_id, section_id])
  }
  ```
* **Coverage Health Analytics:**
  - Exposes `GET /api/syllabus/coverage-summary?class=&subjectId=`: Computes completion ratio:
    $$\text{Coverage Rate} = \frac{\sum \text{Completed Units up to current week}}{\sum \text{Target Units up to current week}} \times 100$$
  - Flags sections falling more than 2 weeks behind schedule in yellow/red on the Principal Executive KPI Dashboard (#87).

##### 2. N30 Live Class Links & Digital Lecture Repository (Premium Tier)
* **Institutional Job:** Centralized timetable-synchronized live video classroom links (Google Meet, Microsoft Teams, Zoom) and structured video/audio lecture repository organized by subject and chapter.
* **Data Models:**
  ```prisma
  model LiveClassSchedule {
    id           String   @id @default(uuid())
    college_id   String
    campus_id    String?
    section_id   String
    subject_id   String
    teacher_id   String
    title        String
    platform     String   // GOOGLE_MEET | MS_TEAMS | ZOOM | YOUTUBE_LIVE
    meetingUrl   String   // Validated HTTPS video link
    meetingPassword String?
    scheduledDate DateTime @db.Date
    startTime    String   // HH:mm
    endTime      String   // HH:mm
    isActive     Boolean  @default(true)
    createdAt    DateTime @default(now())

    @@index([college_id, section_id, scheduledDate])
  }

  model DigitalLectureRecording {
    id           String   @id @default(uuid())
    college_id   String
    campus_id    String?
    subject_id   String
    class        String
    unitId       String?  // Linked to SyllabusUnit
    title        String
    description  String?
    videoSource  String   // EMBEDDED_YOUTUBE | VIMEO | EXTERNAL_URL
    videoUrl     String
    durationMins Int?
    uploadedById String
    isPublic     Boolean  @default(true)
    createdAt    DateTime @default(now())

    @@index([college_id, subject_id, class])
  }
  ```

##### 3. N31 Class Discussion & Moderated Academic Q&A Forum (Premium Tier)
* **Institutional Job:** Subject-specific academic peer discussion boards where intermediate students post homework questions and teachers provide verified answers with moderation filters.
* **Data Models:**
  ```prisma
  model ForumQuestion {
    id           String   @id @default(uuid())
    college_id   String
    campus_id    String?
    subject_id   String
    class        String
    student_id   String
    title        String
    body         String
    isPinned     Boolean  @default(false)
    isClosed     Boolean  @default(false)
    viewCount    Int      @default(0)
    createdAt    DateTime @default(now())
    updatedAt    DateTime @updatedAt

    answers      ForumAnswer[]
    @@index([college_id, subject_id, class])
  }

  model ForumAnswer {
    id           String   @id @default(uuid())
    questionId   String
    authorId     String   // User.id or Student.id
    authorRole   String   // teacher | student
    body         String
    isAccepted   Boolean  @default(false) // Verified/endorsed by teacher
    upvotes      Int      @default(0)
    createdAt    DateTime @default(now())
    updatedAt    DateTime @updatedAt

    question     ForumQuestion @relation(fields: [questionId], references: [id], onDelete: Cascade)
    @@index([questionId])
  }
  ```
* **Content Security:** Text is sanitized with `sanitize-html` to prevent XSS. Abusive posts can be soft-deleted by teachers or principals.
