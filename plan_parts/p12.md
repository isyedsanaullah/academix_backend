#### 12A: N35 Library Management Module (Premium / Add-on on Standard)
* **Institutional Job:** Complete cataloging, accession registry, barcode circulation, student book lending quotas, and overdue fine generation.
* **Data Models:**
  ```prisma
  model BookTitle {
    id          String   @id @default(uuid())
    college_id  String
    campus_id   String?
    isbn        String?
    title       String
    author      String
    edition     String?
    publisher   String?
    category    String   // SCIENCES | LITERATURE | ISLAMIC | REFERENCE | TEXTBOOK
    ddcClass    String?  // Dewey Decimal Classification
    totalCopies Int      @default(1)
    // Note: availableCopies is strictly DERIVED on query to prevent drift:
    // availableCopies = totalCopies - (SELECT count(*) FROM BookIssueRecord WHERE copy.titleId = id AND returnedAt IS NULL)
    createdAt   DateTime @default(now())

    copies      BookCopy[]
    @@unique([college_id, title, author, edition])
    @@index([college_id, category])
  }

  model BookCopy {
    id            String    @id @default(uuid())
    titleId       String
    accessionNumber String  // Unique physical asset number
    barcode       String    // Scannable barcode string
    condition     String    @default("GOOD") // NEW | GOOD | WORN | DAMAGED | LOST
    status        String    @default("AVAILABLE") // AVAILABLE | ISSUED | RESERVED | IN_REPAIR
    addedAt       DateTime  @default(now())

    title         BookTitle @relation(fields: [titleId], references: [id], onDelete: Cascade)
    issues        BookIssueRecord[]
    @@unique([titleId, accessionNumber])
    @@unique([titleId, barcode])
  }

  model BookIssueRecord {
    id            String    @id @default(uuid())
    college_id    String
    campus_id     String?
    copyId        String
    student_id    String?   // Issued to student OR staff
    userId        String?
    borrowerType  String    // STUDENT | STAFF
    issuedAt      DateTime  @default(now())
    dueDate       DateTime  @db.Date
    returnedAt    DateTime?
    fineAmountPkr Int       @default(0)
    fineStatus    String    @default("NONE") // NONE | PENDING | PAID | WAIVED
    issuedById    String

    copy          BookCopy  @relation(fields: [copyId], references: [id])
    @@index([college_id, student_id, returnedAt])
    @@index([college_id, dueDate, returnedAt])
  }
  ```
* **Circulation Rules & Fine Invariants:**
  - Maximum active book loans per student enforced by setting (`library.maxBooksPerStudent`, default 2).
  - Overdue fine calculated daily: $\text{Overdue Days} \times \text{finePerDayPkr}$ (from `CollegeSetting.libraryFinePerDay`, default PKR 10/day).
  - Unpaid library fines automatically post to student's next monthly fee challan as `FINE` line items.

  ```prisma
  model TransportRoute {

  model StudentTransportAllocation {
    id          String    @id @default(uuid())
    college_id  String
    campus_id   String?
    student_id  String
    session_id  String
    routeId     String
    stopId      String
    allocatedAt DateTime  @default(now())
    isActive    Boolean   @default(true)

    route       TransportRoute @relation(fields: [routeId], references: [id])

    // Allows students to change bus stops/routes within a session while deactivated records remain for audit.
    @@index([college_id, student_id, session_id, isActive])
    @@index([routeId, isActive])
  }
  ```
* **Fee Engine Integration:**
  - When the monthly fee generation worker executes, it checks `StudentTransportAllocation WHERE student_id = ? AND isActive = true`.
  - Automatically appends a `TRANSPORT` line item with `amount = route.monthlyFarePkr` to the student's monthly fee voucher.
  - Deallocation stops future voucher line items cleanly.

#### 12F: N40 Double-Entry Accounting & General Ledger (Enterprise Tier)
* **Institutional Job:** Certified double-entry financial system with Chart of Accounts, debit/credit journal vouchers, trial balance, and automatic income statement / balance sheet compilation.
* **Continuity & Seeding from Phase 9 N04:**
  - Reads `AccountHeadMapping` rows created during Phase 9 N04.
  - Automatically seeds standard Pakistani educational Chart of Accounts:
    * `1000`: Assets (Cash at Hand, Bank Al Habib, Meezan Raast, Accounts Receivable)
    * `2000`: Liabilities (Vendor Payables, Security Deposits, Prepaid Student Fees)
    * `3000`: Equity (Institutional Capital, Retained Surplus)
    * `4000`: Revenue (Tuition Fees, Admission Fees, Exam Fees, Transport Revenue, Hostel Revenue, Canteen Margin)
    * `5000`: Expenses (Teacher Salaries, Utilities, Lab Supplies, Software Subscriptions, Repairs)
* **Data Models:**
  ```prisma
  model AccountHead {
    id           String   @id @default(uuid())
    college_id   String
    code         String   // "1010", "4010"
    name         String   // "Cash in Hand", "Tuition Fee Revenue"
    accountType  String   // ASSET | LIABILITY | EQUITY | REVENUE | EXPENSE
    parentCode   String?
    isActive     Boolean  @default(true)
    createdAt    DateTime @default(now())

    journalLines JournalLineItem[]
    @@unique([college_id, code])
    @@index([college_id, accountType])
  }

  model JournalVoucher {
    id          String   @id @default(uuid())
    college_id  String
    campus_id   String?
    voucherNo   String   // JV-YYYY-XXXXX
    voucherType String   // JV (Journal) | PV (Payment) | RV (Receipt)
    voucherDate DateTime @db.Date
    narration   String
    status      String   @default("POSTED") // POSTED | VOIDED
    createdById String
    createdAt   DateTime @default(now())

    lines       JournalLineItem[]
    @@unique([college_id, voucherNo])
    @@index([college_id, voucherDate])
  }

  model JournalLineItem {
    id          String   @id @default(uuid())
    voucherId   String
    accountCode String
    college_id  String
    debitPkr    Int      @default(0)
    creditPkr   Int      @default(0)
    narration   String?

    voucher     JournalVoucher @relation(fields: [voucherId], references: [id], onDelete: Cascade)
    account     AccountHead    @relation(fields: [college_id, accountCode], references: [college_id, code])
    @@index([college_id, accountCode])
  }
  ```
* **Strict Double-Entry Balancing & Immutability Invariants:**
  - **Check Constraint on Lines:** `JournalLineItem` carries a database check constraint ensuring a line cannot have both or neither debit/credit:
    `CHECK (("debitPkr" = 0 AND "creditPkr" > 0) OR ("debitPkr" > 0 AND "creditPkr" = 0))`
  - **Balanced Transaction Check:** Every `POST /api/accounting/vouchers` verifies:
    $$\sum \text{debitPkr} === \sum \text{creditPkr} \quad \land \quad \sum \text{debitPkr} > 0$$
    Rejects unbalanced transactions with HTTP 422 `UNBALANCED_JOURNAL_VOUCHER`.
  - **Audit Immutability Triggers:** `JournalVoucher` and `JournalLineItem` are append-only. Once posted, lines cannot be updated or deleted. Corrections are made via explicit reversing vouchers. Protected by PostgreSQL row-level trigger `trg_journal_immutable` (blocking UPDATE/DELETE) and statement-level trigger `trg_journal_no_truncate` (blocking TRUNCATE with SQLSTATE 55000), identical to `MealAccountTransaction`.

#### 12G: N41 Departmental Budgets & Cost Centres (Enterprise Tier)
* **Institutional Job:** Fiscal year expense allocation per department/campus with real-time budget depletion meters and automated purchase block when requisitions exceed allocated caps.
* **Data Models:**
  ```prisma
  model DepartmentBudget {
    id            String   @id @default(uuid())
    college_id    String
    campus_id     String?  // Absorbs N18 multi-campus budget allocation
    fiscalYear    String   // "2026-2027"
    department    String   // "Physics Dept", "Sports Dept", "Admin & IT"
    allocatedPkr  Int
    consumedPkr   Int      @default(0)
    blockedPkr    Int      @default(0) // Committed in pending POs
    createdAt     DateTime @default(now())
    updatedAt     DateTime @updatedAt

    allocations   BudgetExpenseCommitment[]
    // Coalesced unique index in Postgres to properly handle nullable campus_id:
    // CREATE UNIQUE INDEX "DepartmentBudget_college_fiscal_dept_campus_key" ON "DepartmentBudget" (college_id, "fiscalYear", department, COALESCE(campus_id, '00000000-0000-0000-0000-000000000000'));
    @@index([college_id, fiscalYear, department])
    @@index([college_id, fiscalYear])
  }

  model BudgetExpenseCommitment {
    id          String   @id @default(uuid())
    budgetId    String
    referenceType String // PURCHASE_ORDER | REIMBURSEMENT
    referenceId String
    amountPkr   Int
    status      String   // COMMITTED | SETTLED | RELEASED
    createdAt   DateTime @default(now())

    budget      DepartmentBudget @relation(fields: [budgetId], references: [id], onDelete: Cascade)
    @@index([budgetId, status])
  }
  ```
* **Budget Overspend Blocking Invariant:**
  - When N39 PO is submitted, an atomic transaction checks:
    $$\text{consumedPkr} + \text{blockedPkr} + \text{poAmount} \le \text{allocatedPkr}$$
  - If over budget, rejects with 422 `DEPARTMENT_BUDGET_EXCEEDED` unless authorized by Principal override.
