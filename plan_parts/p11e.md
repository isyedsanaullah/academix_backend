#### 11E: Localization & App Capabilities (N09, N21, N22)

##### 1. N09 Bilingual UI & Right-to-Left (RTL) Document Screens (Starter Tier)
* **Institutional Job:** High-quality Urdu Nastaleeq typography and RTL layout support for official outward-facing institutional documents, notices, fee challans, and guardian mobile screens.
* **Realistic Architectural Scoping:**
  - **Does NOT rewrite internal complex administrative screens** (e.g. Master Timetable Grid or Super Admin Governance) into Urdu.
  - **Strictly Scoped To:**
    1. Generated Printable Documents: Fee Challans (#55), Character Certificates (#30/N29), ID Cards (#31), Circulars (#25).
    2. Student & Guardian Views: #83 Parent Portal PWA screens and in-app notice feeds.
* **Implementation Details:**
  - Standardized font embedding: OpenType `Jameel Noori Nastaleeq` embedded in vector PDF engines (`pdfkit` / Puppeteer print styles).
  - Next.js client layout uses `dir="rtl"` conditionally when user selects Urdu in `#83` language switcher.
  - Localization dictionary stored in JSON (`backend/config/i18n/ur.json`, `en.json`).

##### 2. N21 Notice Templates with Scheduled Dispatch (Standard Tier)
* **Institutional Job:** Reusable, parameterized official communication templates with variable merge tags (`{{studentName}}`, `{{class}}`, `{{dueDate}}`, `{{amountPkr}}`, `{{examDate}}`), capability-flagged on the #25 Circulars engine.
* **Data Models:**
  ```prisma
  model AnnouncementTemplate {
    id           String   @id @default(uuid())
    college_id   String
    campus_id    String?
    title        String   // "Fee Defaulter 2nd Notice", "Rain Emergency Holiday"
    category     String   // FEE_REMINDER | EMERGENCY | EXAM_NOTICE | HOLIDAY | PTM
    bodyTemplate String   // Contains {{tokens}}
    defaultAudience String // ALL | STUDENTS | PARENTS | TEACHERS
    isSystemPreseeded Boolean @default(false)
    createdAt    DateTime @default(now())
    updatedAt    DateTime @updatedAt

    @@unique([college_id, title])
    @@index([college_id, category])
  }
  ```
* **Merge Token Substitution Engine:**
  - When dispatching, tokens are safely interpolated from recipient record context.
  - Prevents script injection by validating token keys against an allowed set.

##### 3. N22 Parent App Web Push Notification Delivery (Premium Tier)
* **Institutional Job:** Native mobile lock-screen push notifications for intermediate student guardians via W3C Web Push standards, delivering instant absence alerts and fee reminder banners without native app store packaging.
* **Architecture & Delivery:**
  - Built on the #83 Parent Portal PWA service worker.
  - Utilizes standard VAPID (`web-push` library) with platform-wide master key pairs.
* **Data Models:**
  ```prisma
  model GuardianPushSubscription {
    id           String   @id @default(uuid())
    college_id   String
    studentId    String
    endpoint     String   @unique
    p256dh       String   // Public encryption key
    auth         String   // Auth secret
    userAgent    String?
    createdAt    DateTime @default(now())

    @@index([college_id, studentId])
  }
  ```
* **Worker Integration:**
  - When `dailyAbsenceAlertWorker` (#86) or circular dispatcher (#25) emits `OutboxEvent`, the `outboxWorker` queries `GuardianPushSubscription` for the target student and delivers web push payloads with high priority.
  - Subscriptions returning HTTP 410 `Gone` or 404 `Not Found` are automatically deleted from the database.
