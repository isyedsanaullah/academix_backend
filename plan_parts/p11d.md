#### 11D: Student Life, Discipline & Alumni (N32, N33, N34)

##### 1. N32 Confidential Discipline & Counselling Records (Premium Tier)
* **Institutional Job:** Secure, role-restricted incident documentation, disciplinary hearing minutes, formal penalty records, and sensitive psychological/guidance counselor notes.
* **Confidentiality & Access Invariants:**
  - **Strictly excluded from #83 Parent Portal and Student Dashboard.**
  - Accessible only to users holding fixed roles `principal` or `admin`, or custom roles holding permission `discipline:view_confidential`. General teachers cannot view counseling logs.
* **Data Models:**
  ```prisma
  model DisciplinaryIncident {
    id              String    @id @default(uuid())
    college_id      String
    campus_id       String?
    student_id      String
    session_id      String
    incidentDate    DateTime  @db.Date
    category        String    // MISCONDUCT | FIGHTING | BUNK | CHEATING | DAMAGE | BULLYING | OTHER
    severity        String    // LOW | MEDIUM | HIGH | CRITICAL
    description     String
    actionTaken     String    // WARNING | FINE | SUSPENSION | PARENT_SUMMON | EXPULSION | NONE
    fineAmountPkr   Int?      // Linked to fine voucher if fine imposed
    suspensionDays  Int?
    reportedById    String
    hearingDate     DateTime?
    isResolved      Boolean   @default(false)
    resolvedAt      DateTime?
    createdAt       DateTime  @default(now())
    updatedAt       DateTime  @updatedAt

    counselingNotes StudentCounselingLog[]
    @@index([college_id, student_id])
    @@index([college_id, category, severity])
  }

  model StudentCounselingLog {
    id           String   @id @default(uuid())
    incidentId   String?
    college_id   String
    campus_id    String?
    student_id   String
    counselorId  String   // Staff userId
    sessionDate  DateTime @db.Date
    sessionNotes String   // Confidential discussion record
    actionPlan   String?
    followUpDate DateTime? @db.Date
    createdAt    DateTime @default(now())

    incident     DisciplinaryIncident? @relation(fields: [incidentId], references: [id], onDelete: SetNull)
    @@index([college_id, student_id])
  }
  ```

##### 2. N33 Events, Sports Teams & Club Management (Premium Tier)
* **Institutional Job:** Extracurricular society management (Debating Society, Science Club, Dramatics, Sports Gala, Cricket/Football teams), member rosters, inter-college tournament registries, and sports trials.
* **Data Models:**
  ```prisma
  model StudentClub {
    id          String   @id @default(uuid())
    college_id  String
    campus_id   String?
    name        String   // "Literary & Debating Society", "Cricket First XI"
    category    String   // ACADEMIC | SPORTS | CULTURAL | SOCIAL_WORK | LEADERSHIP
    description String?
    leadTeacherId String // Club In-Charge / Coach
    presidentStudentId String?
    isActive    Boolean  @default(true)
    createdAt   DateTime @default(now())

    members     StudentClubMember[]
    events      ClubEvent[]
    @@unique([college_id, name])
  }

  model StudentClubMember {
    id          String    @id @default(uuid())
    clubId      String
    student_id  String
    role        String    @default("MEMBER") // MEMBER | CAPTAIN | SECRETARY | VICE_PRESIDENT
    joinedAt    DateTime  @default(now())
    leftAt      DateTime?

    club        StudentClub @relation(fields: [clubId], references: [id], onDelete: Cascade)
    @@unique([clubId, student_id])
    @@index([student_id])
  }

  model ClubEvent {
    id          String   @id @default(uuid())
    college_id  String
    campus_id   String?
    clubId      String
    title       String   // "Annual Inter-Collegiate Debating Championship 2026"
    eventDate   DateTime @db.Date
    venue       String
    description String?
    budgetPkr   Int      @default(0)

    club        StudentClub @relation(fields: [clubId], references: [id], onDelete: Cascade)
    @@index([college_id, eventDate])
  }
  ```

##### 3. N34 Alumni Registry & University Placement Tracker (Premium Tier)
* **Institutional Job:** Graduate tracking database recording intermediate pass-out students' entry-test performance (MDCAT, ECAT, NUMS), university admissions (KEMU, AIMC, NUST, GIKI, FAST, LUMS), and career milestones for marketing and board inspections.
* **Data Models:**
  ```prisma
  model AlumniProfile {
    id                 String   @id @default(uuid())
    college_id         String
    campus_id          String?
    student_id         String?  @unique // Nullable link to historical Student record
    fullName           String
    fatherName         String?
    matricRollNumber   String?
    boardRollNumber    String   // Intermediate 2nd year roll number
    passingYear        Int      // 2024, 2025, 2026
    academicGroup      String   // Pre-Medical, Pre-Engineering, ICS
    finalBoardMarks    Int?
    finalBoardTotal    Int?     @default(1100)
    currentStatus      String   // ENROLLED_UNIVERSITY | EMPLOYED | PREPARING | ABROAD
    universityName     String?  // "King Edward Medical University", "NUST Islamabad"
    degreeProgram      String?  // "MBBS", "BS Computer Science"
    email              String?
    phone              String?
    linkedInUrl        String?
    isTestimonialShared Boolean @default(false)
    createdAt          DateTime @default(now())
    updatedAt          DateTime @updatedAt

    @@index([college_id, passingYear, academicGroup])
    @@index([college_id, currentStatus])
  }
  ```
